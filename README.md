# Трекер прочитанных книг
Консольное приложение на Python для управления личной библиотекой.

## Функции
* Добавление книг с указанием автора, названия, оценки и даты.
* Проверка на дубликаты (нельзя добавить одну и ту же книгу дважды).
* Просмотр списка всех книг.
* Расчет средней оценки и вывод количества книг по каждому автору.
* Удаление книг из списка.

## Как запустить
1. Установите Python.
2. Запустите файл командой: `python main.py`

## Технологии
* Python (JSON для хранения данных)
* Git/GitHub (командная разработка через ветки)
